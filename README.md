# Собаки: три собаки, три игры, один город

Три собаки с разным характером живут в одном городском квартале.

| Игра | Папка | Статус |
|------|-------|--------|
| **Бегун** — гонка по городу, прыжки, погоня за котом | [`runner/`](runner/) | первый этап готов |
| Охранник — патруль, конус зрения, нарушители | — | не начата |
| Нюхач — квест по запахам | — | не начата |
| Собачий квартал — изометрическая песочница (мячик, пудель, нюхач) | корень (`index.html`) | прототип |

## Бегун

Вид от третьего лица, низкая камера, день и ночь.

**Компьютер:** `W` / `↑` разгон, `A` `D` повороты, `S` тормоз, `Пробел` прыжок, `N` день/ночь.

**Телефон:** левая половина экрана — плавающий руль (влево/вправо поворот, вниз тормоз),
правая половина — прыжок. Кнопка «Автобег» держит газ включённым.

Что уже есть: разгон с инерцией и заносом на поворотах, прыжок (буфер нажатия, «койот-время»,
короткий прыжок при раннем отпускании), препятствия (низкие перепрыгиваются, высокие замедляют),
перекрёстки, бесконечная улица из кусков, кот, который убегает, петляет и перепрыгивает преграды,
очки и комбо, переключатель день/ночь.

### Настоящая 3D-модель собаки

Игра работает и без моделей (собака и кот собираются из примитивов). Чтобы подключить модель:

1. Скачай пак **Ultimate Animated Animals** с [quaternius.com](https://quaternius.com) (лицензия CC0).
2. Возьми GLB собаки (например, Husky) и положи как `models/dog_runner.glb`.
3. Кота (если есть) — `models/cat.glb`.

Загрузчик сам масштабирует модель, ставит её на землю и подбирает анимации по именам
(`Idle`, `Walk`, `Gallop`, `Gallop_Jump`). Если модель смотрит не вперёд, поменяй `MODEL_YAW`
в `runner/js/config.js`. Имена найденных анимаций печатаются в консоль браузера.

### Структура

```
runner/
  index.html, css/style.css
  js/config.js      константы и темы день/ночь
  js/materials.js   материалы и их палитры
  js/world.js       улица кусками, перекрёстки, препятствия, границы
  js/models.js      собака и кот: процедурные и GLB
  js/player.js      физика бега, прыжок, столкновения
  js/cat.js         ИИ кота
  js/camera.js      камера от третьего лица
  js/input.js       клавиатура и сенсорное управление
  js/fx.js          пыль и искры
  js/main.js        сцена, свет, цикл, интерфейс
  vendor/           Three.js r128 (MIT), GLTFLoader, BufferGeometryUtils
```

## Запуск локально

```bash
python3 -m http.server 8080
```

Открой `http://localhost:8080/runner/`. Из `file://` открывать нельзя: браузер блокирует
загрузку моделей.

## Технологии

- **Three.js r128** (скрипты лежат в `runner/vendor/`, сеть не нужна)
- Геометрия улицы склеивается в несколько мешей на кусок: около 250 вызовов отрисовки на кадр
- Освещение: полусфера + солнце/луна с тенями + два живых фонаря, скользящих по улице
