# AnimalDesign — экспериментальная копия «Ромашки»

Песочница для нового дизайна (оболочки) игры «Симулятор парикмахера — Академия Льва Кравца».

- Источник: https://github.com/Reactor888r1a1a1/romashka-game888, коммит `2d44924`
- Правило: **тексты, диалоги, алгоритмы и механики не меняются**. Меняется только оформление — CSS, вёрстка, картинки персонажей и фонов.
- Запуск локально: `python3 -m http.server` в корне, открыть http://localhost:8000
