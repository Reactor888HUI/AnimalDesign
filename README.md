# AnimalDesign — экспериментальная копия «Ромашки»

Песочница для нового дизайна (оболочки) игры «Симулятор парикмахера — Академия Льва Кравца».

- Источник: https://github.com/Reactor888r1a1a1/romashka-game888, коммит `2d44924`
- Правило: **тексты, диалоги, алгоритмы и механики не меняются**. Меняется только оформление — CSS, вёрстка, картинки персонажей и фонов.
- Запуск локально: `python3 -m http.server` в корне, открыть http://localhost:8000

## Эталон и проверка (шаг 1)

```bash
cd tools && npm install
node etalon.mjs check   # тексты (1998), данные (95 таблиц), игровая логика (150 функций) — не изменились
node trace.mjs check    # автопроход «Пижона»: 173 события идут так же, как в эталоне
node trace.mjs shots    # скриншоты всех экранов «Пижона» на телефоне → screens/pijon/
```

- `etalon/etalon.json` — отпечатки; `etalon/texts.md` — все тексты игры для вычитки; `etalon/trace-pijon.json` — эталонный ход.
- Что разрешено менять при редизайне — списки `VISUAL_FUNCS` и `VISUAL_DATA` в `tools/etalon.mjs`.

## Скриншоты «до» (шаг 2)

`screens/pijon/index.html` — 164 экрана барбершопа «Пижон»: Эрик, Айя, 8 клиентов.
