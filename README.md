# Собачий квартал 3D

Изометрическая симуляция прогулки трёх собак по городскому кварталу.

## Демо

После включения GitHub Pages: `https://reactor888hui.github.io/AnimalDesign/`

## Собаки

| Собака | Характер |
|--------|----------|
| 🟤 Нюхач | Медленно идёт, часто останавливается понюхать, жёлтые частицы запаха |
| 🔵 Бегун | Очень быстрый, всегда первым бежит за мячиком |
| ⚪ Пудель | Непредсказуемый — отвлекается, бросает начатое |

**Кликни на экран** — бросить теннисный мячик. Собаки реагируют по-разному.

## 3D Модели (опционально)

Игра работает с процедурными мешами. Для настоящих 3D моделей:

1. Скачай бесплатный пак **Ultimate Animals** с [quaternius.com](https://quaternius.com)
2. Распакуй ZIP
3. Найди GLB файлы для трёх пород собак
4. Переименуй и положи в папку `models/`:
   - `models/dog_sniffer.glb` — Лабрадор / Бигль
   - `models/dog_runner.glb` — Борзая / Доберман
   - `models/dog_poodle.glb` — Пудель / Болонка
5. Push и GitHub Pages обновится автоматически

## Запуск локально

```bash
npx serve .
# или
python3 -m http.server 8080
```

Открой `http://localhost:8080`

## Технологии

- **Three.js r128** — 3D рендеринг
- **OrthographicCamera** — изометрический вид
- **GLTFLoader** — загрузка 3D моделей (с fallback на процедурные меши)
- **PCFSoftShadowMap** + ACESFilmicToneMapping — качество картинки
