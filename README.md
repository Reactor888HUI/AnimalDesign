- Передаточный документ (правила, настройки, ссылки, промт для новой сессии): [`docs/HANDOFF.md`](docs/HANDOFF.md)
- Исходник: `arcade/index.html`; офлайн-сборка: `python3 -I tools/build-offline.py` → `dist/vosmerka-baklazhan.zip`
