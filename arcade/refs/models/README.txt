Готовые модели транспорта для потока на автобане. Обе — CC0 (общественное достояние), можно использовать без ограничений;
авторы указаны в подписи внизу страницы игры.

quaternius-bus.obj     — Bus из «LowPoly Public Transport», автор Quaternius
                         https://opengameart.org/content/lowpoly-public-transport  (также quaternius.com/packs/publictransport.html)
kenney-van.obj         — van из «Car Kit» 3.1, автор Kenney
kenney-colormap.png      https://kenney.nl/assets/car-kit

В игру вшиваются конвертером:  python3 -I tools/obj-to-game.py arcade/index.html
(ориентация, масштаб, удлинение середины автобуса, высокая крыша и окна салона маршрутки, цвета и огни — в tools/obj-to-game.py).
