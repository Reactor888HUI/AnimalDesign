# «Восьмёрка Баклажан» — как устроена игра

Для разработчика (и для Claude в новой сессии). Правила игры — `docs/GAME.md`, где какое имя — `docs/CODEMAP.md`, история — `docs/CHANGELOG.md`, план — `docs/TZ.md`.

## 1. Файлы

```
arcade/
  index.html        каркас: стили, разметка экрана (кнопки, меню «⋯», мини-карта), порядок подключения скриптов
  js/01…26-*.js     код игры по разделам — грузятся по порядку номеров
  data/*.js         данные: карта, модели, фото, звуки — пишут инструменты, руками не править
  refs/             исходники: выгрузки OSM (*.osm), модели CC0, фото пользователя, фактуры CC0, песня
tools/              сборка, конвертеры данных, проверки, Blender-скрипты
dist/               сборки для игрока (один файл + zip в git; «папкой» — нет)
docs/               документы
assets/maps/        отдельные ассеты (low-poly карта центра .glb — в игру пока не встроена)
```

### Порядок загрузки страницы
1. `three.min.js` r149 (в рабочей версии — с jsdelivr, в сборках — свой файл). Глобальное имя `THREE`, в коде алиас `T`.
2. `data/*.js` — обычные `const` (`OSM`, `WEST`, `PHOTO_*`, `SUV_DATA`, `WHEEL_DATA`, `VAZ_BODY_DATA`, `VEHICLE_MODELS`, `ENGINE_SND`).
3. `js/01-core.js` … `js/26-frame.js`. Последняя строка `26-frame.js` — `requestAnimationFrame(frame)`: запуск главного цикла.

Все скрипты — классические (не модули): имена верхнего уровня (`const`, `let`, `function`) **общие для всех файлов**. Каждый файл начинается с `"use strict"`. Так работает и с сайта, и прямо из файла на телефоне (`file://`), где браузер запрещает `fetch` соседних файлов, но разрешает `<script src>`.

### Три правила общих имён (важно при правках)
1. **Порядок важен для кода, который выполняется сразу при загрузке.** Функция, объявленная в файле 20, ещё не существует, пока выполняется файл 05. Вызывать её из 05 можно только внутри функций, которые сработают позже (по кнопке, в кадре). Пример: в `23-trainer.js` стоит `addEventListener("fullscreenchange", () => resize())`, а не `…, resize)` — `resize` объявлена в `26-frame.js`.
2. **Имя объявляется один раз на всю игру.** Новое имя проверяй по `docs/CODEMAP.md`. Совпадение со встроенными именами браузера (`top`, `name`, `status`…) сломает загрузку — сейчас таких нет (проверено).
3. **Нельзя `return` на верхнем уровне файла.** Остановить игру при запуске — `halt("текст")` из `01-core.js`: покажет текст игроку и заглушит ошибки следующих файлов.

## 2. Координаты мира
- Метры. Начало — по рамке `arcade/refs/rostov-center.osm` (первая выгрузка в `tools/osm-to-game.py`), **не менять**, иначе сдвинется всё построенное.
- Карта повёрнута на 180°: **запад → +x, юг → −z**. Север основной карты — `z = −82`, за ним вымышленная полоса: автобан (`ZA = −60`, x −600…1400), трюк-парк, полигон, «Восьмёрка».
- Пересчёт широты/долготы: `x = 280 − ((lon − 39.73288)·75660 − 511)`, `z = −82 − (2762 − (lat − 47.19783)·110574)` (точно — функции `local`/`game` в `osm-to-game.py`).
- Данные OSM хранятся в дециметрах (`dm()` в коде).
- Высота земли — `terrainH(x, z)` (сейчас придуманный холм 38 м под основной картой; по ТЗ — настоящие высоты, этап 1), поверхность с мостами и палубами — `surfaceH`/`groundAt`.

## 3. Бюджеты (жёсткие)
| Что | Лимит |
|---|---|
| Кадр | ≤ 150 тыс. треугольников, ≤ 120 вызовов отрисовки (телефон) |
| Старт (код + данные) | ≤ 4 МБ (сейчас 3,84 МБ одним файлом, zip 1,7 МБ — запас мал: новые большие данные — только подгрузкой) |
| Главный экран | Android-телефон в портрете ~400×820 |
| Новый район | отдельными файлами с подгрузкой; квадрат 500 м — ≤ 300 КБ, ≤ 15 вызовов, ≤ 25 тыс. тр. |

Скрипты Blender начинают с `bpy.ops.wm.read_factory_settings(use_empty=True)`: в стандартной сцене есть кубик 2 м в начале координат — при запекании тени он оказывается внутри модели.

Прочие рамки: без сетевых запросов во время игры; шрифты Google — только фоновой загрузкой; у артефакта claude.ai **не объявлять capabilities**; без брендов; чужие модели — только CC0 с подписью; `localStorage["baklan3d-v1"]` — менять формат только с миграцией.

## 5. Проверка
```bash
tools/check.sh          # ~10 мин: синтаксис, сборка, запуск трёх версий без ошибок, бюджет кадра (оба авто, кабина),
                        # «ничего не изменилось» к HEAD (кадры 7 точек + сводка сцены)
tools/check.sh full     # + все автотесты (~40 мин)
tools/check.sh quick main~3   # сравнить картинку с другим коммитом
```
Отчёт — `.check/report.txt`, кадры — `.check/same-*`. Код выхода 0 — всё стабильное прошло.

- **«Ничего не изменилось»** (`tools/arcade-same.cjs` + `tools/same-diff.py`): часы страницы заморожены, `Math.random` с зерном, телепорт в 7 точек, кадр и сводка (вызовы, треугольники, загруженные квадраты). Игра всё равно не повторяет кадр бит-в-бит (шум 0,1–3 уровня яркости), поэтому эталон снимается дважды и «после» сравнивается с шумом эталона. Если картинку меняли нарочно — отличие ожидаемо, смотреть кадры.
- **Стабильные тесты** (блокируют): `arcade-smoke`, `arcade-roads`, `arcade-landing`, `arcade-multitouch`, `arcade-arena`, `arena-race`, `bridge-trainer`, `bridge-audit` (6 174 сценария, физика шагом 1/120 с без отрисовки).
- **Нестабильные тесты** (в отчёт, не блокируют): `arcade-eight`, `arcade-inner`, `arcade-menu`, `arcade-p1`, `arcade-p2`, `arcade-p3`, `arcade-pro`, `arcade-reach`. Причина одна: бот едет по **настоящим часам**, а программная отрисовка в контейнере даёт 1–3 кадра/с — физика считается разными шагами, и от прогона к прогону ложны разные пункты (сравнение 25.10.2026: у старой и новой версии — разные). **Лечение (запланировано):** гнать ботов шагом физики `__t.step(dt)` без отрисовки, как `bridge-audit`, — тогда тест повторяем.
- Тестовые ручки: страница с `#test` → `window.__t` (`teleport`, `info`, `step`, `input`, `suv`, `camSet`, `irace`…, полный список — в `26-frame.js`).

## 6. Как добавить район (по ТЗ, этап 2)
1. Выгрузка OSM квадратами `api.openstreetmap.org/api/0.6/map` (Overpass закрыт) → склейка → `tools/osm-add-relations.py` для рек и больших полигонов.
2. `tools/osm-to-game.py` с якорем `rostov-center.osm` → `arcade/data/<район>.js` (как `osm-west.js`), обрезка — по своей рамке.
3. Сцена — по образцу `WESTSC` в `09-scenes.js` (`addScene`: строится по кускам ≤ 7 мс за кадр, `near` 900 м строится, `far` 1500 м прячется, `drop` 2200 м выгружается).
4. Заповедник (ж/д мост, Арена, трюк-зоны) не перекрывать.
5. `tools/check.sh full`, бюджет в новом районе, `python3 -I tools/codemap.py`.

## 7. Известные ограничения
- Three.js r149 — последняя версия с глобальной сборкой; обновление = переход на модули (отдельный этап, не сейчас).
- Песня вечеринки в рабочей версии (`arcade/index.html` с диска) не играет: `fetch` по `file://` запрещён. В сборках — играет.
- Внутри Арены кадр больше нормы по треугольникам (144–160 тыс.) — известно, см. журнал.
