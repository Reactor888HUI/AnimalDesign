# Словарь предметной области

Одно слово — одно значение, в коде, документах и разговоре. Новое понятие — сюда сначала.

| Слово | Значение | Где в коде |
|---|---|---|
| **восьмёрка** | машина игрока по умолчанию, ВАЗ-2108 (в интерфейсе без марки) | `makeVaz2108`, `carObj` |
| **внедорожник** | вторая машина | `SUV` |
| **машина игрока** | текущее состояние своей машины: положение, скорость, крен, газ | `car`, `free` (до этапа «Игрок» — глобальные) |
| **чужая машина** | упрощённая копия машины другого игрока или призрака, без физики | планируется, `arcade/lib` |
| **поза** | положение и ход машины в данный момент (х, у, z, углы, скорость, руль, флаги) — то, что едет по сети: 24 байта | `arcade/lib/pose.js`, `docs/PROTOCOL.md` |
| **сервер игроков** | небольшой сервер на Python: комнаты и пересылка поз; игры не знает | `server/` |
| **место (слот)** | номер игрока в комнате, 0–6; наименьший свободный | `rooms.py`, первый байт чужой позы |
| **токен возврата** | 22 символа, выдаётся при входе; с ним после обрыва связи возвращаешься на своё место (30 с) | `rooms.py`, `net-client.js` |
| **не в сети** | игрок в комнате, но связь оборвана; место держится 30 с | `players[].online` |
| **режим** | `free` — свободная езда по городу; `level` — уровень полигона; `train` — тренировка | `mode` |
| **фаза** | шаг внутри режима: `run`, `ramp`, `air`, `roll`, `crash`, `free`, `fsink` … | `phase` |
| **сцена** | район карты, который строится при подъезде и выгружается вдали | `SCENES`, `addScene` |
| **площадки (макеты)** | тестовые зоны: автобан, трюк-парк, полигон, «Восьмёрка» — отдельная сцена южнее карты | `TEST`, `TZ` |
| **TZ** | сдвиг площадок по z (−3330 м) | `01-core.js` |
| **автобан** | прямая 2 км с потоком машин на площадках (ось `ZA`) | `ZA` |
| **полигон** | уровни и уроки: разгон, рампа-штопор, ряд машин | `step`, `buildLevel` |
| **ряд** | машины, через которые прыгают на полигоне | `row` |
| **плато** | ровная земля за Садовой, 42 м, там пока пусто | `PLAT` |
| **трасса (трек) «Восьмёрка»** | дрифт-трек из двух петель, шоу 888 | `EIGHT`, `SHOW` |
| **Арена** | Ростов Арена: стадион, трасса вокруг, начинка внутри | `ARENA`, `INNER` |
| **начинка Арены** | горка-труба, аэротруба, «Баклажановый поток», внутренний круг Гран-при | `INNER` |
| **Гран-при Арены** | прототип гонки: светофор, соперники, круги, места | `R0` |
| **задание** | цель свободной езды с очками (мост, слалом, шоу…) | `MISSIONS` |
| **кольцо** | оранжевое кольцо в воздухе, +300 очков | `ring`, `rings` |
| **вечеринка 888** | 8 секунд замедления, салюта и песни после крутого трюка | `PARTY` |
| **PRO** | режим «полёт как в аэротрубе», бесконечный газ | `free.pro` |
| **сопла** | сжатый воздух для прыжка и вращения («ПРЫГ») | `cushion`, `sideJet` |
| **склон (холм)** | правый берег по настоящим высотам | `terrainH`, `HEIGHT` |
| **настил** | поверхность моста над землёй | `DECKS` |
| **круг (гонка)** | один проход трассы по контрольным точкам по порядку | планируется |
| **контрольная точка (чекпоинт)** | ворота на трассе; без прохождения по порядку круг не засчитывается | планируется |
| **призрак** | запись собственного лучшего круга, едет рядом | планируется |
| **комната** | группа 2–7 игроков с кодом из 4 букв; создатель — хозяин | `server/rooms.py`, `net-client.js` (готово, к игре не подключено) |
| **хозяин** | игрок, который ведёт часы, старт и итоги комнаты; при уходе хозяина — наименьшее место из тех, кто в сети | `server/rooms.py` (роль), старт и итоги — планируется |
| **паспорт машины** | файл-данные машины: модель, краска, физика, звук | планируется |
| **гараж** | экран выбора и настройки машины | планируется |
| **пакет машины** | отдельный файл `cars/<id>.js` с паспортом и моделью | планируется |
