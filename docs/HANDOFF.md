# Handoff: продолжение разработки «Собаки» (бегун-уиппет)

Документ для нового чата. Прочитай целиком, потом `docs/prompt-ui-v2.md` (текущий план) и `README.md`.

## 1. Как работать с игроком
- Игрок пишет по-русски, часто голосом (опечатки, «э»). Отвечай **по-русски, коротко, по делу**;
  проблемы и риски — **таблицами**. Отчитывайся честно (что не получилось — так и пиши).
- Игрок тестирует на **Android-телефоне в браузере, горизонтально**, присылает скриншоты.
  После каждого шага — скриншоты с телефона (844×390 и 390×844) и короткий отчёт.
- Большие задачи — сначала промпт/план, вопросы по неясному, потом шагами с контрольными точками.
- В конце шага — предложить следующий шаг, не начинать без согласия (если игрок не сказал «делай дальше»).
- Игрока **укачивает** от резко вращающейся камеры: без крена, тряски, рывков; это всегда проверять.

## 3. Техника
- Three.js **r128**, обычные `<script>` (без сборки), всё в глобальном `window.R`.
- `runner/index.html`, `runner/css/style.css`, `runner/js/*`:
  | Файл | Что |
  |---|---|
  | `main.js` | движок: сцена, свет, пост-обработка (GRADE: лучи, размытие скорости), цикл, `ctx`, меню «⋮», режим камеры `setCam`, полноэкранный режим |
  | `player.js` | физика собаки: скорость, повороты (два режима: «по направлению» `dirMode` и «руль» throttle/steer), прыжки, сальто, отскок от стены, подкат, суперскорость (`superOn`, `energy`), полёт стрелой (`arrow`) |
  | `input.js` | клавиатура и тач: стик, зона прыжка, двойной тап = прыжок, кнопки `.act`, круиз `cruise` (темп держится без пальца), `camLock`; `input._poll` — настоящий poll (тесты подменяют `poll`) |
  | `camera.js` | `CameraRig`: `locked=true` → **«Поводок»** (или `gopro=true` → **«на морде»**, `onHead()`) (`leash()`: жёстко ~1 м за ошейником, высота 1.45, в прыжке выше/дальше); `locked=false` → свободная (палец/мышь, сама медленно заходит за спину ≤24°/с) |
  | `whippet.js` | процедурная модель уиппета: 28 костей (`pelvis, lumbar, chest, neck1, neck2, head, headEnd…`), IK-походка, супергалоп, поза стрелы, окрасы, якоря для гардероба |
  | `modes/runner.js` | режим бегуна: кот, курицы, косточки, кольца, трюки и цепочки, рекорд прыжка, задания |
  | `quests.js`, `wardrobe.js` | задания дня, звёзды, гардероб, вкладка «Рекорды» (`stat()`, `runner-stats` в localStorage) |
  | `street.js` | голуби, листья, провода, прохожие |
  | `map.js` | мини-карта (сейчас спрятана) и большая карта с переносом |
  | `speedfx.js`, `audio.js`, `music.js`, `daytime.js`, `world.js`, `cityworker.js` | полосы скорости, синтез звуков, музыка, время суток, город (стриминг кварталов, Web Worker) |
- Размеры собаки: длина ~1.5 м, голова на высоте ~0.93 м, ошейник (`neck1`) ~0.42 м впереди центра.
- Настройки в localStorage: `runner-cam` (`lock`/`gopro`/`free`), `runner-theme`, `runner-stats`, задания/гардероб.
- После добавления файлов: `node tools/make-sw-list.js` (список офлайн-копии `runner/sw.js`, его проверяет тест 13).

## 4. Тесты
- Playwright, свой раннер: `NODE_PATH=/opt/node22/lib/node_modules node tests/run.js [фильтр]`
  (24 спеки `tests/specs/01…24`, ~5 мин; CI — `.github/workflows/tests.yml`).
- Тесты открывают страницу с остановленным циклом и шагают кадрами сами; `t.open(url, {live, sw, game, viewport})`.
- Для скриншотов: `python3 -m http.server 8765` из корня репо (в фоне), скрипт Playwright с
  `viewport 844×390, hasTouch, isMobile, deviceScaleFactor 2`, Chromium с `--use-angle=swiftshader`.
- Известные редкие случайности: `08-sniffer` (~1 из 7) и `17-map` в части Нюхача (метка «улика» вместо «хозяин»: зависит от того, сколько кадров успело пройти до остановки цикла). Не разобраны.
- Тест 09 (средняя скорость камеры в свободном режиме) ≤15°/с — шумный, обычно 6–12.

## 5. Что сделано (по порядку)
Город и стриминг без «подгрузки», Web Worker, автотесты + CI, трюки и цепочки, время суток, музыка, PWA,
мокрый асфальт и AO, уиппет v2, живые улицы, карта района, лучи, задания дня и гардероб, суперскорость и
полёт стрелой, кнопка «Рывок» и вкладка «Рекорды», затем по жалобам игрока на управление:
- свайп камеры в правильную сторону; камера сама заходит за спину (свободный режим);
- **камера «Поводок» по умолчанию** (жёстко ~1 м за ошейником) — `10a4ac9`;
- управление «руль» на стике: в стороны — поворот, вверх — темп, назад — стоп; отпустил — бежит дальше;
  **двойной тап = прыжок**;
- **одна кнопка «⋮»** вместо кнопок сверху и мини-карты: задания и гардероб, карта, камера, звук,
  время суток, весь экран, выбор собаки; пока открыто — пауза (`ctx.paused` → `body.ui-open`);
- **чистый экран** (бегун) — `9fc1445`: во время бега нет текста вообще (ни панелей, ни стрелки «где кот»,
  ни цепочки трюков, ни тостов); `ctx.say` во время бега только пишет в журнал; цифры и последние
  события — в «⋮ → Забег»; кнопки — полупрозрачные иконки (↑ прыжок, ↘ подкат, ⚡ рывок);
  на телефоне по первому касанию — весь экран и горизонтальная ориентация.

## 6. Что дальше (план в `docs/prompt-ui-v2.md`, решения игрока там же)
3. ✅ **Камера «на морде» (GoPro)** — `CameraRig.onHead()` + `holdHead()`: камера по верхней точке качания
   головы, голова в этом виде удерживается ровно перед камерой (15 % качания); шапка/очки скрыты,
   в сальто собака скрыта (`rig.hideDog`, `camDress()` в main.js). Кнопка `#camBtn` и клавиша `V`
   перебирают поводок → на морде → свободная. Тест 24.
4. **Новое управление**: руль правым пальцем (вести влево-вправо); **переключатель передач**
   шаг → рысь («тусит») → бег → галоп → суперскорость (один элемент, без текста); слева повыше две
   кнопки «Прыжок» и «Подкат». Игроку нравится просто гулять шагом/рысью — анимации должны быть хорошими.
5. **Режим «Поиск»** (только на шаге и рыси): собака опускает морду и нюхает; на земле любой текстуры
   проявляются полупрозрачные тонкие светящиеся нити-фракталы, ведут вперёд в разные стороны, **все цвета
   радуги + коричневый**. **Клубки** спутанных светящихся нитей у мусорных баков с дымком того же цвета
   (сложнее, чем шарики у Нюхача). Задания: «Радужный след», «Клубок у баков», «Потерянный мячик»,
   «Колбаска», «Кот в засаде», «Чужая метка», «Тихая прогулка», «Нос к земле».
6. **Гардероб**: собака должна быть видна (в портрете — в верхней половине), панель ≤45 %, полупрозрачная,
   вещи — лентой; подсказки внутри панели.

Открытые мелочи: в портретной ориентации на поводке шея собаки занимает низ экрана; новому игроку некому
подсказать управление (подсказка только в «⋮»); Охранник и Нюхач пока со старыми панелями и свободной камерой.

## 7. Ограничения игрока (действуют всегда)
- Не ломать анимации, управление, камеру, коллизии, логику; имена и иерархию костей уиппета не менять;
  треугольников не больше ×2; без тяжёлой пост-обработки; стиль low-poly.
- Телефон должен держать частоту кадров. Клавиатура на компьютере должна работать.
- Каждый шаг: тесты зелёные, где поведение меняется намеренно — тест переписан и сказано почему; QA-чек-лист.
