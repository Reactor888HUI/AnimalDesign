## 2. Как запустить

- **Телефон (основной способ).** Скачать `vosmerka-baklazhan.zip`, распаковать, открыть `index.html` в Chrome. Интернет не нужен: Three.js и песня встроены в файл. Старые скачанные копии лучше удалить, чтобы не путать версии.
- **Компьютер.** Открыть артефакт по ссылке выше или тот же `index.html`.
- **Для разработки.** Открыть `arcade/index.html` (подтянет `js/` и `data/` рядом). Three.js грузится с jsdelivr. Песня вечеринки с диска по `file://` не читается: без сборки вечеринка идёт без музыки. С музыкой — только офлайн-сборка.
