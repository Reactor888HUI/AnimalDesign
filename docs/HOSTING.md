# Игра по ссылке: хостинг

Решение заказчика (27.10.2026): **сервер + запасное прямое соединение**, начинаем с раздачи файлов. Здесь — что готово и что делает человек с аккаунтом (я с вашего имени ничего не публикую на сторонних сервисах).

## Что готово
- Сборка «папкой»: `python3 -I tools/build-offline.py` → `dist/vosmerka-web/` (`index.html`, `js/`, `data/`, `vendor/three.min.js`). Это обычный статический сайт: любой хостинг, который отдаёт файлы.
- Проверено `tools/arcade-http.cjs` (входит в `tools/check.sh`): сайт открывается по `http://`, **из вложенной папки адреса** (`/AnimalDesign/`, как на GitHub Pages), без ошибок, без потерянных файлов, `isSecureContext = true` (на `localhost`). Значок вкладки встроен в обёртку сборки.
- Одиночная игра остаётся **офлайн-первой**: `zip` и один файл `index.html` работают как раньше.

## Куда выложить (выбирает человек с аккаунтом)
| Вариант | Как | Заметки |
|---|---|---|
| Cloudflare Pages / Netlify | создать проект, загрузить папку `dist/vosmerka-web` | проще всего: репозиторий и ветки не нужны; бесплатные тарифы есть, актуальные условия смотреть на сайте сервиса |
| GitHub Pages | включить в настройках репозитория; нужна публикация из ветки или Actions | на бесплатном тарифе — для публичных репозиториев; сборку (`build-offline.py`) надо запускать в Actions, так как `dist/vosmerka-web` в git не хранится; игра лежит в нашей рабочей ветке, не в `main` |
| Свой сервер | любой веб-сервер отдаёт папку; для Python: `python3 -m http.server -d dist/vosmerka-web 8000` (только проверка у себя) | HTTPS нужен для установки на экран и некоторых функций |

Адрес должен быть **HTTPS**: прямое соединение (WebRTC) и WebSocket на странице с HTTPS работают только с защищённым адресом (`wss://`).
