## 2. Чего не хватает (по важности для ваших планов)
1. **Игрок — глобальный синглтон.** `car`, `free`, `mode`, `phase`, `carObj` — одна машина на весь код (53 вызова `Math.random`, трафик/суда/мост считаются у каждого по-своему). Для 2–7 игроков нужна сущность `Player` (локальный + удалённые «прокси» без физики).
2. **Бюджет кадра не вмещает несколько машин.** 7 машин × ~21 вызов = ~147 вызовов и ~160 тыс. треугольников — больше всего лимита (120 / 150 тыс.) без города. Нужны упрощённые «чужие» машины (≤3 вызова, ≤4 тыс. треугольников, один материал с цветами вершин, по возможности экземплярами).
3. **Нет сети вообще**: ни связи, ни лобби, ни синхронизации часов. Нет общего мира: трафик, суда, подъёмный пролёт, поезд у каждого свои.
4. **Нет гоночного ядра для города:** трасса как данные (контрольные точки, ширина), возврат на трассу, «не туда», таймер круга, лучший круг и призрак, старт с решётки, итоги. Прототип у Арены есть — его надо обобщить.
5. **Нет левого берега и маршрута** через мосты обоих берегов (этап 2 из ТЗ). Это самая длинная работа, её можно вести параллельно (разведка данных не трогает код игры).
6. **Нет формата машины и гаража.** Сейчас машины — код (`makeVaz2108`) и один большой блок данных внедорожника; физика, звук, колёса, глаз водителя зашиты в код. Нет загрузки машин «по требованию».
7. **Трафик в городе отсутствует** (он остался на автобане площадок). Для гонки по городу нужно решение: пустые улицы, лёгкий поток или «призраки-такси».
8. **Не проверено на настоящих телефонах** (кадры/с, нагрев, сеть). Тестовый браузер рисует без видеокарты.
9. **Технический долг:** 4 нестабильных теста (p1, «Восьмёрка», inner, меню); начинка Арены выше бюджета кадра; файл у лимита 4 МБ; сохранение без версии миграций.

## 3. Мультиплеер: как строить
**Модель: каждый считает свою машину сам, сеть передаёт позы.** Физика не детерминирована, поэтому синхронизируем состояние, а не ввод.
- **Транспорт:** WebRTC DataChannel. Позы — «ненадёжный» канал без порядка (20–30 раз в секунду), события (старт, чекпоинт, круг, финиш) — надёжный.
- **Топология:** звезда с хозяином комнаты (до 6 соединений у хозяина). Хозяин рассылает старт, часы, результаты и состав комнаты. Для 7 игроков сетка «каждый с каждым» (21 канал) не нужна.
- **Пакет позы** ~24 байта: x, y, z (квантованные), курс, тангаж, крен, скорость, руль, флаги (в воздухе, занос, тормоз, фары). Интерполяция с буфером ~100 мс.
- **Столкновения:** в первой версии — **без** (прозрачные «призраки» при сближении). Мягкие толчки — позже, если захочется.
- **Часы:** хозяин присылает время; клиенты оценивают сдвиг по пингам. Старт гонки — «через 3 с по часам хозяина».
- **Общий мир:** суда, поезд, пролёт моста и светофоры — детерминированные от общего времени и числа-зерна комнаты (заменить `Math.random` в этих модулях). Трафик в гонке — выключен или тоже из зерна.
- **Рекорды:** время круга считает каждый у себя; хозяин проверяет порядок чекпоинтов и минимальное время (для игры с друзьями этого достаточно).
- **Безопасность:** по сети передаются только данные (числа), **никогда код**. Машина соперника — по идентификатору из гаража; если такой модели у вас нет — запасной силуэт.

**Как соединяться без своего сервера** (нужно ваше решение, см. раздел 6):
| Способ | Плюсы | Минусы |
|---|---|---|
| Обмен «кодом комнаты» вручную (текст/QR; описание соединения ~0,6 КБ, с адресами ~1–2 КБ) | Ничего не нужно, работает офлайн в одной сети | На 7 игроков — 6 обменов у хозяина, неудобно |
| Крошечный посредник-«почтальон» для обмена кодами (бесплатный облачный сервис) | Вводишь короткий код комнаты — всё | Внешняя зависимость, нужно завести |
| Сервис «Артефакты» (общее хранилище страницы) | Без отдельного сервера | В проекте запрещено объявлять capabilities — нужно ваше разрешение |

**Сеть извне:** для разных сетей нужен STUN (бесплатные есть), но у части мобильных операторов соединение напрямую не получится — нужен TURN (есть бесплатные тарифы, но с регистрацией). Внутри одной Wi-Fi сети работает без них.
**Проверено:** `RTCPeerConnection` и канал данных открываются в тестовой среде (`isSecureContext = true`), доставка 100 из 100 пакетов в одной странице. **Не проверено:** работает ли WebRTC и обращение к STUN внутри окна «Артефакта» на claude.ai (там может быть ограничение), и между двумя настоящими телефонами.

## 4. Гараж и разные машины
**Паспорт машины — данные, а не код.** Один файл-пакет на машину:
- `id`, название, автор, лицензия (только бесплатные CC0/CC-BY; без настоящих марок и логотипов);
- модель: кузов с цветами вершин и «тенью» (как у `vaz-body`), колёса, точки подвески и колёс, глаз водителя, зеркала, габариты;
- слоты краски (что красится, что нет), варианты обвеса;
- физика: масса, тяга, сцепление, макс. скорость, расход сопловой тяги, крен/тангаж;
- звук: профиль мотора (параметры синтеза), громкость сопел;
- уровень разблокировки и цена в очках.
Параметры физики выносим из кода в этот паспорт; оба нынешних авто переводим в него первыми (с доказательством, что езда не изменилась).

**Хранение и загрузка:**
- Встроенные машины — в файле игры (бюджет 4 МБ: больше двух-трёх туда не влезет).
- Остальные — пакеты `cars/<id>.js` рядом с игрой (подключаются тегом `<script>`, как `data/*.js`, работает и с `file://`). Загружаются только выбранные.
- Ваши собственные — кнопка «добавить машину из файла» (читается как данные, не как код), хранится в IndexedDB (в `localStorage` не влезет).
- Сеть: передаётся только `id` машины + краска + обвес. Нет пакета у игрока — упрощённый силуэт нужного размера.

**Гараж (экран):** вращающаяся машина, краска и обвес, колёса, характеристики-полоски, «выбрать / купить / проверить на трассе». Выбор запоминается в сохранении (версия формата поднимается с миграцией `baklan3d-v1`).
**Упрощённая версия для других игроков:** автоматическая сборка из полной модели (снижение числа треугольников + один материал с цветами) на этапе сборки пакета — чтобы не рисовать каждому чужому такси за 20 вызовов.

## 6. Решения, которые нужны от вас
1. **Как соединять игроков:** код вручную/QR (проще, но неудобно), бесплатный посредник для кодов (удобнее, но внешняя зависимость), или разрешить общее хранилище «Артефактов» (в проекте сейчас запрещено).
2. **Где играете вместе:** все в одной Wi-Fi сети (проще) или в разных сетях (понадобится TURN).
3. **Столкновения:** без них в первой версии (рекомендую) или сразу мягкие.
4. **Трафик в городской гонке:** пустые улицы / лёгкий поток / «призраки».
5. **Откуда третья и следующие машины:** бесплатные CC0 модели, ваши модели (прислать), или собираем сами в Blender по чертежу/фото.

## 7. Риски
- WebRTC в окне «Артефакта» и на мобильных сетях может не заработать без TURN — этап 0 даёт ответ раньше, чем мы вложимся в код.
- Бюджет: чужие машины, городской круг и красивые дома вместе упрутся в 150 тыс. треугольников — нужны LOD и экземпляры.
- Файл у лимита 4 МБ: всё новое — отдельными пакетами по требованию.
- Левый берег — самая длинная и самая «рисковая по красоте» работа, её нельзя оставлять на конец.

## 8. Принципы ub-mode → решения этого плана
| Принцип | Как применяем |
|---|---|
| Одно решение — в одном месте | ТЗ = что и зачем; порядок = этот файл; правила и инструменты = `QUALITY.md`; слова = `GLOSSARY.md` |
| Сначала данные, потом логика | поза (24 байта, ✔), паспорт машины, трасса, пакеты событий — формы данных первыми |
| Тест вперёд | у каждой единицы раздела 5 — «первый тест» |
| Передизайн с нуля, не «прикручивание» | сеть не навешиваем на глобальные `car`/`free`: сначала `Player` (C2) |
| Атаковать посылку | сомневаемся в посылках плана: «гонке нужна точная синхронность мира» (нужна только у судов/моста — от общего времени, остальное по позам); «каждая чужая машина — полная модель» (нет, ≤ 4 тыс. треугольников); «гараж = загрузка кода» (нет, данные); «трасса — это Арена» (нет, трасса — данные) |
| Сначала убрать | C1 до любых новых фич; площадки на юге — уже пример (город стал легче: 69 вместо 92 вызовов) |
| Цель, которую можно проверить | «готово, когда» в каждой строке |
| Построить рычаг | `tools/quality`, `arcade-same` (кадры), симулятор сети на двух страницах (B1) |
| Моделировать предметную область | паспорт, трасса, комната — структуры, где невозможное состояние не записывается |
