Скопируйте всё, что ниже черты, в новую сессию Claude Code (или отдайте разработчику). Порядок задач — по приоритету, сверху вниз.

## Роль и цель
Ты доделываешь браузерную 3D-игру «Восьмёрка Баклан» — аркаду про испытательную «восьмёрку» (ВАЗ-2108) с холодногазовыми соплами, по мотивам показа летающего родстера 15.10.2026. Цель — сделать игру удобной и стабильной на телефоне, добавить смысл (задания, прогресс) и не сломать то, что уже работает.

## Ограничения среды (обязательно)
- Внешние скрипты — только с cdnjs, jsdelivr/npm, unpkg, с точной версией. Шрифты — только Google Fonts. Всё остальное (модели, звуки, картинки) — внутри файла или рядом через относительный путь.
- Нельзя: iframe, `alert/confirm/prompt`, датчики наклона без capability, скачивание файлов ссылкой.
- `localStorage` — только в try/catch. Ключ сохранения `baklan3d-v1`: открытые уровни, рекорды, цвет, управление, ассистент, мини-карта. Прогресс игрока не терять, формат менять только с миграцией.
- Основная аудитория — **телефон в портрете** (~400×820). Проверять каждое изменение на этой ширине.

## Устройство кода (оглавление по комментариям `/* ---------- … ---------- */`)
- **Параметры.**
  - Полигон: `G=14`, рампа-штопор `RS/RL/RH`.
  - Мир: ось автобана `ZA=-60`, `VMAXF=55` м/с, `WORLD`, `SPAWN`.
- **Ростов** (раздел «Ростов: настоящий район из OpenStreetMap»). Полоса 1 × 2,8 км повёрнута на 180°: Богатяновка примыкает к автобану с севера (−z), дальше набережная, Дон (~520 м), левый берег с Ростов Ареной, Левобережной и гребным каналом.
  - `ROADS`, `WATER`, `PIERS`, `ZONES`, `STRIP`; дома — `solids` с полем `rings` (настоящий контур, столкновения по многоугольнику через `inBox`), сетка `solidsNear()`.
  - Вода: `waterAt()` → `sink()`. Дон продолжен за края полосы, левый берег — только через игровой понтонный мост `BRIDGE` (в реальности тут моста нет) или по воздуху.
  - Плоские крыши — земля сверху: `groundAt(x, z, y)` возвращает `roof`.
  - Названия мест: `placeName()` — ближайшая улица, затем зона (парк, Арена, Акватория), затем район.
- **Режимы** (переменная `mode`):
  - `free` — свободная езда, физика `stepFree`;
  - `level` — уровни 1–5 на полигоне, физика `step`;
  - `train` — пять уроков `DRILLS`.
- **Физика.** Единицы — метры и секунды. Ось `x` — вперёд по автобану, `y` — вверх, `z` — вбок.
  - Машина: `car.{x,y,z,yaw,v,vy,roll,om,pitch}`. Модель стоит на `y + WHEEL(0.65)`.
  - Посадка оценивается по `rollErr` и `vy`. Пороги `CLEAN_*` и `HARD_*`.
  - Трамплины — `kickers` + `groundAt()`. Препятствия — `solids` + `hitSolid()`.
  - Отбойники (`walls`) — только декорация, коллизий нет. Это сделано специально.
- **Управление.**
  - Режимы `save.ctrl`: `joy` (плавающий джойстик `joy`), `wheel` (руль `wheel` + педаль `pedal`), `buttons`. Геттеры `thr()`, `brk()`, `turn()` (аналоговые, 0…1 и −1…1) складывают все источники.
  - Кнопка ПРЫГ: `free.hopReq`.
  - Клавиатура: `KEYS`.
  - Старые кнопки — в «⋯» → «Управление».
- **Режим тестов** `#test`: `window.__t` — `teleport`, `setCar`, `car`, `zone`, `path` (поиск пути по сетке препятствий), `missions`, `best`, `traffic`, `fast`, `draw` и др.
- **Модель машины** — `makeVaz2108()`, процедурная, лофт по сечениям. Все размеры — через `H(мм)`/`X(мм)` с заводского чертежа: 4006×1650×1402, база 2460, колея 1400/1370.
  - **Не менять пропорции «на глаз».** Проверять видами `#side`, `#front`, `#rear` (добавить к адресу страницы).
- **Интерфейс.**
  - Постоянно на экране: скорость, очки, мини-карта «нос вверх» (`drawMini`), кнопка «⋯».
  - В «⋯»: карта, «Куда ехать», настройки.
  - Подсказки живут 3 секунды. Прибор крена появляется только в воздухе.
  - Правило: на экране не должно висеть ничего лишнего.
- **Отладка.**
  - `#garage` — облёт машины камерой.
  - `#side`, `#front`, `#rear` — чертёжные виды.

## Как проверять
1. Перед каждым коммитом — синтаксис: `node -e` с `new Function(...)` по содержимому `<script>`.
2. Дымовой тест: `PW=$(npm root -g)/playwright node tools/arcade-smoke.cjs` — он должен вернуть `"ok": true`.
3. Своё поведение проверять в Playwright:
   - Chromium `/opt/pw-browsers/chromium` с флагами `--use-gl=swiftshader`;
   - обязательно `page.clock.install()` и `clock.runFor(ms)`, иначе физика в headless тормозит;
   - скриншоты на 400×820.
4. Нельзя писать «работает», если не проверено. В отчёте отдельно перечислять, что не проверено (особенно настоящий телефон и FPS).

### P1 — ощущение езды ✅ сделано 19.10.2026
Итог:
- **Звук.** Синтезируется в коде (`sfx`): мотор с «передачами», шипение сопел, визг шин в заносе, удар при посадке и столкновении, звон кольца, «вжух» прыжка. Включается по первому касанию. Кнопка «Звук» в «⋯» (`save.sound`).
- **Заносы.** Боковая скорость `car.vl`, сцепление шин. Тормоз с рулём на скорости срывает машину в занос, за занос дольше 1 с даются очки. Крен кузова в повороте (`bodyRoll`), нос поднимается при разгоне и клюёт при торможении (`bodyPitch`). На газу у стены машину можно довернуть на месте.
- **«Руль + педаль».** Третий режим в «⋯» → «Управление»: джойстик → руль + педаль → кнопки. Левая половина экрана — руль, правая — газ, потянуть вниз — тормоз. Двумя пальцами одновременно, проверено через CDP.
- **Камера.** На заднем ходу поднимается и приближается. Не заходит в дома: если дом прямо за машиной, вид поверх капота.

Тесты: `tools/arcade-p1.cjs`. В `#test` добавлены `drift()`, `sound()`, `cam()`, `houses()`.

**Не проверено:** звук на слух (тестовый браузер без колонок, проверено только что AudioContext запущен без ошибок) и ощущения на настоящем телефоне.
5. **Звук** (Web Audio, генерировать в коде, без файлов):

6. **Физика заносов:** боковое скольжение на скорости, лёгкий крен кузова в повороте, наклон носа при разгоне и торможении. Сейчас машина поворачивает «как по рельсам».
